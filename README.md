# Strange Wolves MMA

Website for Strange Wolves MMA, Galway.

## Current setup

- Static HTML/CSS/JavaScript site
- Production domain: `strangewolves.ie`
- AWS hosting: S3 behind CloudFront
- GitHub repository is the source of truth for website changes

## Deployment

Until DNS is fully delegated, the site can be previewed directly through the CloudFront test distribution. Once the ACM certificate for `strangewolves.ie` is issued, the production domain can be attached without changing the site code.
